# Tomento Capilar

Sitio web institucional de Tomento Capilar, orientado a presentar sus tratamientos, metodología de trabajo, resultados y canales de contacto.

## Tecnologías

- Next.js
- React con JSX
- CSS Modules
- JavaScript

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Verificación

```bash
npm run lint
npm run build
```

El contenido y las imágenes definitivas se incorporarán progresivamente después de validar la estructura visual con la clienta.
